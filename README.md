# TMBSPACESHIPS Archive

A searchable archive of 1,641 public posts by [@TMBSPACESHIPS](https://x.com/TMBSPACESHIPS) (Electric Propulsive Spacecraft Systems), collected through the public X API. Every post links to its original on X.

**Live site:** https://damianotobasco.github.io/tmbspaceships-archive/

Static HTML/CSS/JS, no build step or dependencies. Search runs in the browser.
